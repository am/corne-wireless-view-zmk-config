Adobe Helvetica Bold bitmap fonts from the X11 distribution (100 dpi set, with
Markus Kuhn's ISO 10646-1 extension), taken from the font collection in
https://github.com/olikraus/u8g2 (tools/font/bdf).

Each glyph was drawn by hand for its size, so the fonts are used pixel for
pixel. The copyright and permission notice is in the header of each file.
